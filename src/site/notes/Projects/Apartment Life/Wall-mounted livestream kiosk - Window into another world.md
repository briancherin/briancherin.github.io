Earlier this year (2026), I was at *Manatee Lagoon* in West Palm Beach, Florida - it's an educational center with wildlife viewing. Inside the center, there was a TV displaying a livestream of an underwater cam.

Of course, that's not the first wildlife livestream I've come across. But it staged my mind. A while later, an idea came to me: having a small display mounted somewhere in my apartment which would have an always-on wildlife^[doesn't necessarily have to be wildlife, but I'm not sure what else it would be] livestream displaying. It's a very passive thing, not something to be constantly watched, but something to occasionally notice. 

I made^[AI-assisted] a simple custom site that searches YouTube for wildlife livestreams and then displays a random one, with some basic settings such as to rotate through them at a specified interval. Code can be found here: https://github.com/briancherin/wildlife-livestream

I am using an old Amazon Fire tablet and installed the "Fully Kiosk Browser" app^[via APK file since Fire doesn't use the Play Store], which lets me specify a URL (where I've deployed the webapp) and it will keep the webpage locked on the screen, always in fullscreen mode. (I guess it's better than just using a browser, so it's fullscreen all the time and keeps the display on.)

The plan is to mount the tablet somewhere on my wall. This step remains to be done.

The deployed webapp is at https://display.briancher.in/.
